**aria2** 是一个极其轻量级、开源、且支持多协议的**命令行下载加速工具**。

它之所以在技术圈非常流行，主要是因为以下几个核心特点：

### 1\. 它是下载界的“多面手”

它支持几乎所有常见的下载协议：

-   **常规协议**：HTTP / HTTPS / FTP
-   **P2P 协议**：BitTorrent (BT 种子、磁力链接 Magnet)
-   **流媒体/传输**：Metalink

### 2\. 为什么它下载这么快？

-   **多线程/分段下载**：它能把一个大文件切成好几块，同时从服务器下载不同的部分，从而榨干你的带宽。
-   **多源下载**：如果你下载的文件在好几个不同的网址或 BT 网络里都有，它能**同时**从 HTTP、FTP 和 BT 种子里面一起拉取数据，合成一个文件。

### 3\. 轻量与低消耗

虽然功能强悍，但它是一个纯命令行工具，对系统资源的占用极低。在后台挂着下载时，内存和 CPU 占用几乎可以忽略不计，因此非常适合部署在服务器、软路由、NAS 或树莓派上。

### 4\. 支持远程控制（WebUI）

虽然 aria2 本身没有图形界面，但它支持 RPC（远程过程调用）协议。这意味着你可以把它运行在服务器后台，然后用浏览器打开网页端（如 *AriaNg* 或 *YAAW*）来可视化地管理、添加、暂停下载任务，体验就像用迅雷一样方便。

---

### 💻 怎么安装和使用？

#### 在 Linux (Ubuntu/Debian) 上安装：

```bash
sudo apt update && sudo apt install -y aria2

```

#### 基本使用命令：

-   **普通单链接下载**：

```bash
aria2c "https://example.com/file.zip"

```

  

-   **多线程分段下载**（比如用 16 个线程同时下）：

```bash
aria2c -s 16 -x 16 "https://example.com/file.zip"

```

  

-   **下载 BT 种子 / 磁力链接**：

```bash
aria2c "/path/to/file.torrent"
# 或者直接下磁力
aria2c "magnet:?xt=urn:btih:..."

```

## 创建一个文件夹存放你的项目

在windows中创建一个文件夹 E:\\code\\blog

> tips
> 
> 文件夹的路径尽量避免使用中文和特殊字符，尽量使用纯英文路径

​  

## 构建项目结构

不同的包管理工具使用不同的构建方式

### pnpm

```plain
pnpm create vuepress-theme-hope my-docs
```

### yarn

```plain
yarn create vuepress-theme-hope my-docs
```

### npm

```plain
npm init vuepress-theme-hope@latest my-docs
```

  

> tips
> 
> my-docs是一个参数，替换为你实际的项目名称

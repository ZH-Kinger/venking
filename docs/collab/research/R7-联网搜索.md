# R7 联网搜索选型(researcher 取证)

> 结论:**DDG(`ddgs`)免 key 起步/回退,Tavily 作默认精准后端(免费 1000 credits/月),博查作中文/合规备选。** config `web_provider` 做成三选一工厂。

## 1. DuckDuckGo — 已改名 `ddgs`
- 包从 `duckduckgo-search` 改名 **`ddgs`**(聚合多后端元搜索),当前 `9.14.4`,需 Python≥3.10。安装:`pip install -U ddgs`。
- 调用(参数名 `query` 不是旧的 `keywords`):
  ```python
  from ddgs import DDGS
  results = DDGS(timeout=5).text("query", region="cn-zh", safesearch="moderate", max_results=5, backend="auto")
  ```
- 返回每条 dict:`title` / `href` / `body`。
- **限流(2026 仍严重)**:频繁 `RatelimitException`(429)。应对:tenacity 指数退避+jitter、≤1 req/s、缓存、`backend=` 换后端(bing/brave/google/mojeek/startpage/yandex…)、必要时 proxy。**注意:其"无限流"DHT 加速仅 Linux/macOS,Windows 吃不到**(本项目在 Windows)。
- 来源:pypi.org/project/ddgs, github open-webui#6624, MetaGPT#1567

## 2. Tavily(为 RAG 优化,推荐默认)
- `tavily-python 0.7.26`,`pip install -U tavily-python`(import 名 `tavily`)。
  ```python
  from tavily import TavilyClient
  resp = TavilyClient(api_key="tvly-...").search(query="...", max_results=5, search_depth="basic")
  ```
- 返回 `resp["results"]`:每条 `title`/`url`/`content`(LLM 友好摘要)/`score`;**天然带 url+content,最适合喂 RAG**。
- 需 key;**免费 1000 credits/月,无需信用卡**(basic=1 credit)。单用户够用。
- 来源:docs.tavily.com/sdk/python/reference, /documentation/api-credits

## 3. 博查 Bocha(国内/中文/合规备选)
- 纯 HTTP(裸 requests,契合"不套 langchain"):
  - `POST https://api.bochaai.com/v1/web-search`,`Authorization: Bearer <key>`
  - body:`{"query":"...","freshness":"noLimit","summary":true,"count":8}`(count≤50)
  - 返回 `data.webPages.value[]`:`name`/`url`/`snippet`/`summary`/`siteName`/`datePublished`
- 需 key(按次计费需充值)。来源:open.bochaai.com, github BochaAI/bocha-search-mcp

## 4. 统一 schema + 带 URL 引用作答
归一化到 `{title, url, snippet}`,再复用本地 `[S#]` 引用模式(source 换成 URL,用 `[W#]`):
- ddgs:title→title, href→url, body→snippet
- tavily:title→title, url→url, content→snippet
- bocha:name→title, url→url, snippet/summary→snippet

拼 web 上下文:`[W{i}] {title}\n{snippet}\n(来源: {url})`;prompt 令 LLM "仅依据 [W#] 作答、句末标 [W#]、末尾列 URL"。本地 `[S#]` 与联网 `[W#]` 可共存、出处可点击。

## 5. 健壮性(工程收口)
provider 层:`timeout=5` + tenacity 退避(DDG 尤需)+ 捕获异常后**降级下一 provider 或返回空**(联网失败不拖垮问答)+ 查询级缓存(对 DDG 缓解 429 最有效)。

# ADR-0014: 弃答机制 —— CRAG 证据打分(生成前) vs 关键词匹配(生成后)
- 状态: 已采纳
- 日期: 2026-07-14
- 相关模块: M5

## 背景(为什么要做这个决策)
系统要能诚实弃答:本该有据、但 KB 与联网都查不到时,说"不知道 + 缺什么",绝不臆造。难点在**联网兜底**:免费 provider(DDG)被限流时常返回无关首页/泛泛结果,模型会照着"半答"(实测"手册作者"题 faithfulness=0.5,半臆造)。怎么可靠地把"联网没答案"转成诚实弃答,而不是让模型硬答?

## 选项(≥2,每个一句话)
- A 生成后关键词匹配:模型答完,在输出里找"无法回答/未提及"等词 → 归一为 refuse。
- B 生成前证据打分(CRAG,选中):联网结果先过 grade_web(LLM 判"这些结果能不能回答问题"),不相关直接 refuse,根本不进生成。
- C 强约束提示词:让 web 提示词在答不出时输出固定开头,再靠关键词识别。

## 优劣对比
| 方案 | 优 | 劣 |
|---|---|---|
| A 生成后关键词 | 零额外调用、实现简单 | 脆:措辞千变万化(查不到/暂无/未涉及…),词表永远漏;且已经把无关内容喂进生成、浪费且有半答风险 |
| B 生成前打分(选中) | 把关口提到生成前,不相关就不生成→根治半答;语义判断比关键词稳 | 每次联网兜底多一次 LLM 调用(关思考 ~1s) |
| C 强约束提示 | 比纯关键词稳一些 | 仍依赖模型遵守格式 + 关键词识别,双重不确定 |

## 结论(选了哪个)
主力用 **B CRAG 证据打分**:新增 `grade_web` 节点,联网结果生成前判相关性,不相关→refuse。同理检索侧用 `grade_documents`(复用 rerank 分,不额外调 LLM)做细筛。关键词归一(A)**降级为最后兜底**(grade 失败时保守放行,由护栏关键词再兜一层)。形成三道防线:证据打分(生成前)→ 生成 → 护栏(生成后)。

## 为什么不选替代
- 不选 A 当主力:实测它是脆的——"手册作者"题联网返垃圾、模型用"查不到"之类不在词表的措辞半答,关键词没抓到、faithfulness 掉到 0.5。关键词匹配是 whack-a-mole,不是原则性设计。
- 不选 C 当主力:仍把无关内容喂进生成(浪费+半答风险),且依赖模型遵守格式;B 从源头避免。
- 保留 A/C 作兜底:多一层廉价防线符合"加冗余/防御纵深",grade_web 调用失败时不至于裸奔。

## 回溯条件(什么情况下该重估)
- grade_web 误杀率高(把相关结果判成无关)→ 调打分提示或阈值,或换更强判官。
- 换成高质量联网 provider(Tavily/博查)后垃圾结果大减 → 可评估 grade_web 是否仍必要。
